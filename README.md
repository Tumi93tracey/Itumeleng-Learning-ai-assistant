# Itumeleng's Learning Hub

Build a functional, polished AI-powered education productivity assistant based on the attached project brief and teaching portfolio. Target teachers, parents, and learners, with strongest focus on ECD/early-years literacy and CAPS-aware planning. Brand it around Itumeleng Kgaswane's educator profile. Include an interactive AI assistant/chatbot and at least these practical tools: lesson-plan generator, parent email/message generator, meeting/parent-conversation notes summarizer with action items, task planner, and research/resource helper. Make AI prompt engineering visible through well-structured guided input forms, role/audience/tone controls, and useful output formats. Include realistic education-specific problems/use cases and solutions, responsible-AI safeguards, privacy/verification reminders, and sample/demo content so it works as a portfolio project even before users enter information. Create a dashboard and responsive professional UI suitable for a live demo. Use Lovable Cloud/AI where appropriate to make generation functional.
